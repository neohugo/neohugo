# go-html — porting notes

Port of go1.27.1 `html` (`EscapeString`, `UnescapeString`) with Go's full
entity table.

## Go file → Rust module map

| Go (go1.27.1 `$GOROOT/src`) | Rust |
|---|---|
| `html/escape.go` (replacementTable, unescapeEntity, htmlEscaper, EscapeString, UnescapeString) | `src/lib.rs` |
| `html/entity.go` (longestEntityWithoutSemicolon, entityMaps: `entity` 2,138 names, `entity2` 91 names) | `src/entity.rs` (generated) + lookups in `src/lib.rs` |
| `unicode/utf8.EncodeRune` | `src/utf8.rs` (private copy) |

`src/entity.rs` is generated by `go run ./tools/go-oracle/go-html -entities
crates/go-html/src/entity.rs`: the oracle parses `$GOROOT/src/html/entity.go`
with `go/parser` (so entries commented out in Go, e.g. `nLt;`/`nGt;` whose
replacement is wider than their name, stay out), evaluates the rune literals
with `go/constant`, sorts by name and cross-checks every entry against
`html.UnescapeString("&"+name)` before writing. Lookups are binary searches
over the sorted tables (Go uses maps; lookups are exact-match either way).

## Public API

```rust
go_html::escape_string(&str) -> String            // html.EscapeString
go_html::escape_string_bytes(&[u8]) -> Vec<u8>
go_html::unescape_string(&str) -> String          // html.UnescapeString
go_html::unescape_string_bytes(&[u8]) -> Vec<u8>
go_html::entity(name: &[u8]) -> i32               // entity[name], 0 if absent ("amp;", "amp", ...)
go_html::entity2(name: &[u8]) -> [i32; 2]         // entity2[name], [0,0] if absent
go_html::entities() / entities2()                 // iterate the tables
```

The `&str` forms are exact: both functions only rewrite ASCII-led sequences
and every rune they emit is valid UTF-8 (invalid code points become U+FFFD),
so valid UTF-8 in means valid UTF-8 out.

## Semantics reproduced

* Numeric references accumulate in a Go `rune` (int32) with wrapping
  arithmetic (`&#99999999999;` wraps, then goes through the range checks);
  `x > 0x10FFFF`, 0 and surrogates become U+FFFD; 0x80–0x9F use the
  Windows-1252 replacement table; a negative wrapped value reaches
  `utf8.EncodeRune`, which writes U+FFFD.
* `&#` needs at least one more byte (`len(s) <= 3` check) and at least one
  digit consumed (`i <= 3` check), so `&#1a` stays literal while `&#12` decodes.
* Named references: longest alphanumeric run (+ optional `;`), exact match
  in `entity` then `entity2`, else the longest prefix of at most 6 bytes
  (`longestEntityWithoutSemicolon`) found in `entity`.
* In-place rewriting of a copy of the input (`dst <= src`), as in Go.
* `EscapeString` is Go's `strings.NewReplacer` with five single-byte olds
  (a `byteStringReplacer`), i.e. an independent per-byte mapping:
  `&`→`&amp;`, `'`→`&#39;`, `<`→`&lt;`, `>`→`&gt;`, `"`→`&#34;`.

## Deliberate deviations

* `utf8.EncodeRune` is a private copy (`src/utf8.rs`) so the crate has no
  dependencies; `go-unicode` holds the canonical port.
* The `attribute` constant of `unescapeEntity` is `false` in Go and the
  corresponding branch is kept as dead code, as in Go.

## Verification

Oracle: `tools/go-oracle/go-html -fixtures <file> [-n N] [-seed S]
[-inputs F -only-inputs]`. Each line holds input, `html.EscapeString` and
`html.UnescapeString` output.

* `tests/fixtures/unescape.txt` (26,416 cases): all string literals of
  `$GOROOT/src/html/*_test.go`; every entity name bare, followed by a
  letter, `=` or itself, without its `;`, with a bogus suffix and
  uppercased; every `entity2` name; `&#N;`, `&#xN;`, `&#XN`, `&#N` for
  N < 0x140 and for surrogates, 0x10FFFF±1, int32/uint32 overflow values;
  hand-picked edge cases; 8,000 random soups of `&`, `#`, digits, entity
  prefixes, invalid UTF-8 and NULs.
* `tests/fixtures/golden-sample.txt` (983 cases): lines containing `&` from
  the golden seeksnack HTML output.
* Plus Go's own `unescapeTests` and `TestUnescapeEscape` as unit tests.
* Scratch corpora: 618,416 cases (`-n 600000 -seed 7`) and 7,856 cases
  from all golden lines containing `&` (`-only-inputs`) — all identical, release and debug builds.

### Independent adversarial verification (second agent)

* Oracle mode `-adv N` (`tools/go-oracle/go-html/adversarial.go`): every
  prefix of every `entity`/`entity2` name followed by 15 suffixes (``, `;`,
  letters, digit, `=`, `&`, space, é, Thai, `\xff`, `;;`, `&amp;`, `#`,
  `0;`), every no-semicolon entity followed by every byte (bare and inside
  text) and by letter/digit pairs, and N random soups of glued entity
  fragments, alphanumeric runs, `&#`/`&#x` references up to 30 digits
  (int32 wrap-around), stray `&`/`;`/NUL/invalid UTF-8.
* Scratch runs: seed 3 (604,721 cases, release and debug), seeds 31 and 32
  (704,721 each): 2,014,163 cases, 0 mismatches.
* `tests/fixtures/adversarial.txt` (8,119 cases, `-adv 20000 -seed 5
  -every 40`) is checked in and run by `oracle_adversarial`.
* Mutation check on the adversarial corpus: `longestEntityWithoutSemicolon`
  6→5 (6,877 mismatches), `i <= 3`→`i < 3` (12,478), dropping `x == 0`
  (1,903), prefix `src + j + 1`→`src + j` (21,374). Survivors are
  equivalent mutants: `j > 1`→`j > 0` (no 1-byte entity names),
  `maxLen = len` (the full name was already looked up), `len(s) <= 3`→`<= 2`
  (a 3-byte `&#.` can never match a digit and pass `i <= 3`).
