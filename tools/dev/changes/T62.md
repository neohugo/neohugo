# T62: reconstruction parity (gate A-R)

The first seeksnack baseline: `testdata/baselines/seeksnack.json`. The Rust build of the
seeksnack reconstruction equals the Go build at L1 (713/713 in both passes), L2 (427/427),
L4 (179/179), the structure oracle (673/673: 288 records, 84 resources, 196 pages, 95 pagers,
10 aliases) and in the visible text of every page (A7 1.0, 228/228). Fixed in this task:

- undated pages print Go's zero time (`Jan 1, 1`, `January 1, 1`, Thai `1 ม.ค. 1`, year `1`):
  the `single/date.html` partial formats a none date as `0001-01-01T00:00:00Z`, and
  neohugo-locale's medium, long and full date styles no longer add ICU's era to early years
  (`Jan 1, 1 AD`), as Hugo's CLDR patterns;
- a bundled content page's `.MediaType` is `application/octet-stream` (Hugo's type of every
  page), not the media type of its content file (`text/markdown`).

The one difference left:

- seeksnack L3 `project:hugo_stats.json` engine-difference: the classes of `<th>` (`a-left`, `a-right` from render-table.html) are recorded; Hugo loses them because it parses each tag alone with net/html, which drops a lone `<th>` (a Go implementation quirk, §1.2)

Not a harness difference, recorded for review: with `canonifyURLs = true`, the
`resources.PostProcess` CSS link (`<link rel="preload" href=…>`) is absolute in our output
(`https://seeksnack.com/scss/…`) and root-relative in Go's (`/scss/…`): Go canonifies before
it replaces the post-process placeholders, neohugo-publish canonifies a held output again
after patching it, by design, so post-processed links follow the site's URL style. L2
normalises both to the same internal link. `v1.html`'s inner rendering (listed as a possible
`accepted-deviation` in §7.3) equals Go's and needs no entry.

The gate runs as `cargo test -p neohugo --test it reconstruction` (`tests/it/reconstruction.rs`:
`compare.sh seeksnack --ref golden` with the built binary; SKIPPED without python3, the node
tools or esbuild), or against a fresh Go build with `tools/neohugo/compare.sh seeksnack`.
